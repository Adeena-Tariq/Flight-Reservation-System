# ✈️ Flight Reservation System

A console-based Flight Reservation System developed in **C++** using Object-Oriented Programming (OOP) concepts. The system simulates real-world airline booking operations including flight management, passenger reservations, ticket generation, and payment processing.

---

## 📌 Description

This project provides a user-friendly airline reservation simulation where users can browse flights, book tickets, manage passenger details, and generate reservations through a modular console interface. It demonstrates core OOP principles such as abstraction, encapsulation, modularity, and association in a real-world application.

---

## 🚀 Features

-  Flight Management
-  Passenger Management
- Schedule Management
-  Airport Management
-  Ticket Generation
-  Payment Processing
-  Reservation System
-  Seat Availability Checking
-  Menu-Driven Console Interface

---

## ⚙️ System Workflow

1. User logs into the system
2. Browse available flights
3. Enter passenger details
4. Select flight and reserve seat
5. Process payment
6. Generate reservation ticket
7. View or print ticket

---

## 📂 Main Classes

| Class | Responsibility |
|------|------|
| Flight | Flight details & seat management |
| Passenger | Passenger information |
| Reservation | Booking and confirmation |
| Airport | Airport data management |
| Schedule | Flight timings & durations |
| Payment | Payment simulation |
| Ticket | Ticket generation |
| Reservation System | Central system controller |

## 💻 How to Run

```bash
g++ main.cpp -o flight_system
./flight_system
```
